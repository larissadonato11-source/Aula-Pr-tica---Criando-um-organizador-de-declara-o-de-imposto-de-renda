# Aula Prática - Criando um organizador de declaração de imposto de renda
Projeto desenvolvido como entrega do case prático DIO. O objetivo da aplicação é criar um organizador de declaração de imposto de renda no Excel.

# 📊 Template de Organização de Dados Cadastrais e Financeiros

Uma solução simples e estruturada em planilha (Excel) voltada para a centralização, organização e controle de dados pessoais, informes de rendimentos bancários e movimentações para declarações.

# 📌 Sobre o Projeto
Este projeto consiste em uma estrutura organizada para consolidação de dados financeiros e cadastrais do titular. O objetivo é facilitar o levantamento de informações para processos como declaração de Imposto de Renda.

A planilha é dividida em quatro abas principais:

- Titular: Cadastro completo de dados pessoais do titular e dados de contato.

- Informes: Registro de dados bancários, saldos/valores atuais e anexos de informes de rendimentos.

- Notas: Histórico detalhado de entradas, receitas e movimentações financeiras por data e categoria.

- Tabelas: Base de dados de suporte contendo códigos e nomes de instituições bancárias e categorias para validação de dados.

# 🛠️ Funcionalidades e Abas

1. Dados do Titular (TITULAR)
Estrutura padronizada para registro seguro e centralizado dos dados do indivíduo:

Nome completo
CPF e Título de Eleitor
Data de Nascimento
Nome do Cônjuge
Endereço completo (Rua, Número, CEP)
Informações de Contato (Telefone e Celular)

2. Informes de Rendimentos (INFORMES)
Área para acompanhamento de ativos e saldos bancários:

Métrica Total: Soma automática ou consolidação de valores guardados/investidos.
Detalhamento por Instituição: Seleção de instituição financeira (ex: C6 Bank, Santander, etc.), valor atual e referência/link para os arquivos de comprovante (.pdf).

3. Registro de Entradas (NOTAS)
Controle de receitas e entradas mensais de recursos:

Data: Data exata da entrada financeira.
Categoria: Classificação da receita (ex: Holerite, Rendimentos, Serviços, etc.).
Valor: Montante recebido em moeda local.

4. Tabelas de Apoio (TABELAS)
Lista de referência usada para validações de dados nas demais abas:

Lista oficial de Bancos (ex: 033 - Banco Santander, 260 - Nubank, 336 - C6 Bank, 104 - Caixa Econômica Federal, etc.).
